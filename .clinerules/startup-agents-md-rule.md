## Brief overview
This rule defines startup behavior for Cline in this repository. This is a project-specific rule that applies to all sessions started in this workspace.

## Startup behavior
- Always read and follow the instructions contained in `agents.md` at the very beginning of every new session
- Comply with all policies, conventions, and operational workflows documented in `agents.md` before proceeding with any user task
- This requirement applies to both PLAN MODE and ACT MODE sessions
- Do not skip this step for any task type

## Additional notes
- This rule takes precedence over any default or global Cline behavior
- If `agents.md` is modified during a session, refresh and apply updated instructions immediately
